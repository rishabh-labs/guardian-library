# Drop newsletters here

Anyone on the team can add a newsletter to the library without asking anyone.

## How

1. Open this folder on GitHub and choose **Add file -> Upload files**.
2. Put the file inside a folder named after the **fund house**. When uploading,
   type the path in the "Name your file..." box, e.g.

       inbox/Marcellus/Sept 2026 investor letter.pdf

   If the house already has a folder, just open it and upload into it.
3. **Commit changes** at the bottom.

The site rebuilds itself within a few minutes and the newsletter appears on the
Newsletters page, grouped under that fund house alongside everything the
collectors found on the fund house websites.

## Naming

The filename becomes the title, so name it the way it should read.

Put the month in the name and it will be filed under that month:
`Sept 2026`, `September 2026` and `2026-09` all work. Without one, the date the
file was uploaded is used.

## Accepted

PDF, Word, Excel, PowerPoint, and images.

## One thing to be careful about

**Everything in here is public.** This repository is public and the site is open
to anyone with the link. If a fund house sent you something in confidence, do
not put it here - upload it through the portal running on the office machine
instead, which deliberately keeps private newsletters off the published site.
